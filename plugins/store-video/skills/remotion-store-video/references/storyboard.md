# 商店视频分镜

## 标准结构（Safe Cleanup，886×1920，30fps，897 帧 ≈ 29.9s）

| 段 | 帧 | 时长 | 内容 |
|---|---|---|---|
| 封面 | 0–30 | 1s | 卖点标题（2–3 行）+ App 图标 + App 名 + 金色麦穗五星 |
| 钩子 | 30–120 | 3s | 痛点：存储条填满、变红、抖动 + 一句“Storage almost full.” |
| 功能 1 | 120–250 | 4.3s | 一键清理 → 扫描 → 重复照片 → 删除 → 存储回绿 → 完成弹窗（钩子之后直接进，不加标题卡） |
| 标题卡 2 | 250–272 | 0.7s | 编号图标 + 功能标题 |
| 功能 2 | 272–520 | 8.3s | 截图扫描 → 建议清理 → 删除 → 剩余截图飞入分类 → 完成弹窗 |
| 标题卡 3 | 520–542 | 0.7s | |
| 功能 3 | 542–677 | 4.5s | 隐私照片识别 → 创建相簿 → 照片飞入相簿 → 完成弹窗 |
| 标题卡 4 | 677–699 | 0.7s | |
| 功能 4 | 699–855 | 5.2s | 选图 → 隐私扫描逐条出风险 → 清理 → 结果页 → 保存成功 |
| 结尾 | 855–897 | 1.4s | 回到封面 |

Cleaner Pro（≈28.7s）结构相同：封面 → 4 个功能（清理 / 重复 / 网速 / 体检），每段前有短标题。

## 时长分配经验
- 总长 ≤30s（商店上限）。封面 + 结尾 ≈ 2.5s，标题卡每张 ≈ 0.7s（22 帧），其余均分给功能，复杂功能多给。
- 切点对齐 120 BPM：每拍 15 帧、每小节 60 帧。重要动作（点按、完成）尽量落在拍上，BGM 的鼓点会和画面对上。
- 一个功能只讲一条主线：**点按 → 过程 → 结果 → 完成弹窗**。每一步至少停 10–15 帧让人看清；节奏太快就用 `TimeCtx` rate 0.8–0.9 拉长，而不是删步骤。

## 画面手法
- 点按：手指/光圈出现在按钮上，按钮 `press` 缩小回弹，下一屏 `Push` 推入。
- 数字：存储数字、百分比用 `ip` 滚动，颜色随状态从红到绿（`colorAt`）。
- 镜头：手机 UI 不放在实体手机框里，而是整屏铺满或做成悬浮卡片，用缓慢推拉（`camAt` 缩放/平移）聚焦到操作区域。
- 完成弹窗 `DonePopup`：半透明黑遮罩 + 白色圆角卡片，**绿色勾在上，标题和副标题居中**，配彩纸。
- 标题卡 `TitleCard`：蓝色渐变底 + 白色圆角图标 + 向外扩散的圆环 + 标题逐行上滑。
- 转场：`CrossIn` 轻微缩放+模糊淡入；封面离场时放大淡出。
