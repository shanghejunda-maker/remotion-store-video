# 多语言

## 做法
- `i18n.ts` 导出 `LANGS`（如 `["en","es","pt","fr","de","ja","ko","zh-TW"]`）和每种语言一份 `Dict`。屏幕上**所有**文字都从 `useT()` 取，组件里不写死字符串（App 名除外，所有语言都不翻译）。
- 带数字的文案写成函数：`freed: (x) => \`${x} Freed\``、`toClean: (n) => \`${n} to clean\``。语序不同的语言（日/韩/德）在函数里自己排。
- `index.tsx` 按 `LANGS` 循环注册 `<PascalId>-<lang>`，`defaultProps={{ lang }}`；`Promo` 用 `LangCtx.Provider` 下发。
- `useT()` 额外给出：`lang`、`num(v)`（按地区格式化小数，如德语 `1,8`）、`unit`（法语 `Go`，其余 `GB`）、`cjk`（日/韩/繁中）。
- 根节点设 `lang={t.lang}`，让浏览器选对 CJK 字形。

## 防溢出
- `fit(text, maxW, base)`：按估算字宽算出不超过 `base` 的最大字号，让最长那一行放进 `maxW` 像素。标题、按钮、弹窗标题都用它：
  `fontSize: fit(t.headline.join("\n"), 860, 112)`
- CJK 不用负字距：`letterSpacing: t.cjk ? 0 : -2`。
- 德语/法语最长，写完先在 Studio 里切到 `-de`、`-fr` 看每张标题卡和弹窗。

## 新增语言
1. `LANGS` 加代码，`LOCALE` 加地区。
2. 复制 `en` 的 Dict 翻译（类型会提示缺哪个键）。
3. `npx tsc --noEmit`，在 Studio 里逐段看一遍。

## 翻译注意
- 商店视频要短：标题 2 行内、每行 ≤ 3–4 个词；按钮用 App 内真实文案。
- 示例数据（姓名、证件名）也要本地化（“SAMPLE NAME / 見本 太郎 / 홍길동”）。
- 地名、文件名这类“截图里的内容”可以保持英文。
