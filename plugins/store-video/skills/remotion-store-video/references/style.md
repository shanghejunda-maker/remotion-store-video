# 视觉风格

这些是做过几轮商店视频后，用户（需求方）明确给过的反馈。新项目默认遵守，用户另有要求时以用户为准。

## 要
- **细字体**：正文、副标题用 400–500；标题最多 600–700。避免满屏 800 粗黑体。
- **封面简洁**：一句卖点 + 图标 + App 名 + 评级，留白充足；不要堆砌功能点、标签、截图。
- **完成弹窗**：勾在上方，标题、副标题在下方**居中**（模板 `DonePopup` 已按此实现）。
- **产品 UI 来自设计稿**：按 Figma 手搓页面，保证清晰、可做局部动画；颜色、圆角、文案与 App 一致。
- **节奏清楚**：每个功能一条主线，关键结果（释放了多少、整理完成）停够时间再走。
- 统一的品牌色渐变底（如蓝 `#2f6fe8 → #6db8ff`），标题卡、封面、结尾一致。

## 不要
- **生硬的手机框 mockup**（实体 iPhone 外壳摆在中间）。UI 直接铺满或做成浮起的卡片/局部特写。
- **照搬竞品排版**。竞品只用来参考节奏和信息量，布局、配色、转场要自己的。
- 一屏塞多个动作；文字和动作同时抢注意力。
- 用有版权的音乐、字体、图片。

## 自检清单（预览时过一遍）
- [ ] 每种语言的标题卡、按钮、弹窗都没溢出、没被截断
- [ ] 封面第一帧就好看（商店会用作海报帧）
- [ ] 结尾回到封面
- [ ] 音效和点按/完成对得上
- [ ] 总时长 ≤30s，尺寸正确
